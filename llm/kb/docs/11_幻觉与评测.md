# 幻觉与评测

## 什么是幻觉

幻觉（hallucination）是指模型生成了看起来流畅、自信，但实际上错误或无中生有的内容。例如编造不存在的论文、给出错误的数字、虚构人物经历等。

幻觉的主要原因：
- 模型的本质是预测"最可能的下一个词"，它追求的是说得通顺，而不是说得正确；
- 模型参数有限，记不住所有知识，遇到不熟悉的问题时倾向于"编"一个答案；
- 训练数据本身可能包含错误或过时的信息；
- 模型通常没有被训练过说"我不知道"。

参数越少的模型，知识储备越少，幻觉问题越严重。

## 减少幻觉的方法

1. 检索增强生成（RAG）：让模型依据检索到的资料作答，而不是凭记忆；
2. 严格的提示词：明确要求"只根据资料回答，资料中没有就说不知道"；
3. 要求标注引用：答案中标注资料编号，既约束模型，又方便人工核对；
4. 拒答训练：在微调数据中加入"资料中没有答案"的样本，教模型如实说明；
5. 使用较低的温度或贪心解码，减少随机性；
6. 对重要答案进行事后校验，例如检查答案中的关键内容是否能在资料中找到。

## 为什么要做评测

改进一个系统时，不能只凭感觉判断好坏。应当准备一套固定的评测题，每次改动（换模型、改切分方式、做微调）之后都用同一套题测一遍，用数字对比效果。

## 检索评测指标

- 命中率 Hit@k：正确资料出现在检索结果前 k 条中的问题比例。例如 Hit@5 为 90%，表示 90% 的问题能在前 5 条中找到正确资料。
- MRR（平均倒数排名）：正确资料排名的倒数的平均值。排第 1 得 1 分，排第 2 得 0.5 分，排第 3 得约 0.33 分，没找到得 0 分。

检索效果决定了整个 RAG 系统的上限：如果正确资料没有被检索到，模型再好也答不对。

## 回答评测指标

- 正确率：答案是否包含了正确的关键信息，可以用关键词匹配自动判断，也可以人工打分；
- 引用正确率：答案引用的资料是否确实包含答案；
- 拒答正确率：对知识库中没有答案的问题，模型能否正确地说"不知道"；
- 错误拒答率：明明资料中有答案，模型却说不知道的比例，越低越好。

拒答正确率和错误拒答率需要一起看：一个什么都说"不知道"的模型，拒答正确率是 100%，但毫无用处。

## 困惑度

困惑度（perplexity）是语言模型常用的内部指标，等于平均交叉熵损失的指数，可以理解为模型在每个位置平均"在多少个候选词之间犹豫"。困惑度越低，说明模型对这类文本越熟悉。但困惑度不能直接反映回答是否正确，评测问答效果还是要看上面的任务指标。
