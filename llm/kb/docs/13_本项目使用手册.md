# 本项目使用手册

## 项目简介

本项目是一套低成本的知识训练工具：把你自己的知识库文档"教"给一个开源小模型（Qwen2.5-0.5B 或 1.5B），训练完成后，模型不需要再查阅任何资料，直接就能回答知识库里的问题。整个过程不需要显卡，普通电脑就能完成，也不需要调用任何收费接口，所有数据都保存在本地。

知识库在本项目中只作为训练材料使用。训练分为三个环节：先把文档切成段落；再用底座模型把每段资料改写成多种说法、并出成问答题；最后把原文、改写和问答混合起来，用 LoRA 方法训练模型，把知识写进模型参数里。

## 为什么要改写和出题

研究发现，只让模型把原文读几遍，它往往能"背诵"原文，却不能在被提问时说出其中的知识。同一条知识需要以多种不同的说法出现，模型才能真正掌握并灵活运用。所以本项目会把每段资料用几种风格改写（通俗讲解、要点笔记、换句式复述、百科式介绍），并根据资料出问答题，让模型同时学会"知识本身"和"被问到时怎么回答"。

## 安装

1. 安装 Python 3.9 或更高版本；
2. 在项目根目录运行 `pip install -r llm/requirements.txt` 安装依赖。国内网络可以加上清华镜像：`pip install -r llm/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`；
3. 如果电脑有 NVIDIA 显卡，需要按 PyTorch 官网的说明安装 CUDA 版本的 PyTorch，否则只会使用 CPU；
4. 可选：安装 `llama-cpp-python`，生成训练数据的速度可以提高 2～4 倍。

## 快速开始

依次运行以下命令：
1. `python llm/main.py check`：检测电脑配置，测试算力，推荐底座模型大小并估算训练时间；
2. `python llm/main.py download`：下载底座模型。无法访问 huggingface.co 时会自动改用国内镜像 hf-mirror.com；
3. `python llm/main.py auto`：一键完成切分、改写、出题、生成训练集和训练；
4. `python llm/main.py chat`：在命令行中提问；或者运行 `python llm/main.py web`，然后用浏览器打开 http://127.0.0.1:8000 在网页中提问。

## 分步训练

`auto` 命令等价于依次运行下面五步，每一步都可以单独运行：
1. `python llm/main.py build`：把知识库文档切成段落；
2. `python llm/main.py rewrite`：用不同说法改写每段资料，默认每段改写 2 种；
3. `python llm/main.py gen-qa`：根据每段资料出问答题，默认每段 3 道；
4. `python llm/main.py build-train`：混合成训练集，并留出 10% 的问答作为评测题；
5. `python llm/main.py train`：进行 LoRA 训练，默认训练 3 轮。可以先加 `--max-samples 50` 试跑。

每一步都支持断点续跑：中途关机后重新运行同一条命令，已经完成的部分会自动跳过。训练中断后运行 `python llm/main.py train --resume` 可以接着训练。

## 用自己的文档训练模型

把文档放进 `llm/kb/docs` 文件夹（可以建子文件夹），支持 md、txt、html、pdf、docx 格式，删除自带的示例文档，然后运行 `python llm/main.py auto --rebuild` 重新生成训练数据并训练。如果想使用其他文件夹，可以运行 `python llm/main.py build --docs 文件夹路径`。

知识库有改动时需要重新训练。Markdown 文档中的标题（# 开头的行）会被用来划分小节，建议用标题组织内容，模型能更好地把知识和主题对应起来。

## 评测

`python llm/main.py eval` 会在不提供任何资料的情况下向模型提问（闭卷考试），统计回答正确率。`python llm/main.py eval --base` 用同样的题测试原版底座模型，两者对比就能看出训练学到了多少知识。评测题包括 `llm/kb/eval.jsonl`（针对示例知识库）和训练时自动留出的问答题。

## 常见问题

问：回答速度太慢怎么办？
答：可以换用 0.5B 模型训练（加参数 `--size 0.5b`），或者训练完成后运行 `python llm/main.py merge` 合并模型，再按提示转换成 GGUF 量化格式，用 llama.cpp 运行，速度通常能提高 2～4 倍。

问：模型答错或者记不住知识怎么办？
答：可以增加改写的种类（`rewrite --per-passage 4`）、多出一些问答题（`gen-qa --per-passage 5`）、增加训练轮数（`train --epochs 5`），或者换用更大的 1.5B 模型。出题和改写用的模型越大，训练数据质量越高，可以用 `--model` 指定更大的模型来生成训练数据。

问：训练后模型的通用能力会变差吗？
答：LoRA 只训练很少一部分参数，对模型原有能力的影响较小。如果发现通用能力明显下降，可以减少训练轮数或降低 LoRA 的秩。

问：生成的文件保存在哪里？
答：所有生成的文件（模型、训练数据、训练结果、评测报告）都保存在 `llm/data` 文件夹中，删除后可以重新生成。
