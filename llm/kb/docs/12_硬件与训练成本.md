# 硬件与训练成本

## 如何查看自己电脑的配置

Windows 系统：
- 按 Ctrl + Shift + Esc 打开任务管理器，点击"性能"选项卡，可以看到 CPU 型号、内存大小，以及显卡（GPU）型号和专用显存大小；
- 也可以打开"设置 → 系统 → 系统信息"查看 CPU 和内存；
- 按 Win + R，输入 dxdiag 回车，在"显示"页面可以看到显卡信息。

Mac 系统：点击左上角苹果图标 →"关于本机"，可以看到芯片型号和内存大小。

在本项目中，也可以直接运行 `python llm/main.py check`，程序会自动检测 CPU、内存、显卡，测试算力，并推荐合适的模型大小。

## 内存需求估算

运行（推理）一个模型需要的内存约等于：参数量 × 每个参数的字节数，再加上一些额外开销（KV 缓存、程序本身等）。
- 0.5B 模型：4bit 量化约 0.4GB，16 位约 1GB，32 位约 2GB；
- 1.5B 模型：4bit 量化约 1GB，16 位约 3GB，32 位约 6GB；
- 7B 模型：4bit 量化约 4.5GB，16 位约 15GB。

LoRA 微调时，底座模型权重不需要梯度，内存主要用于底座权重和中间激活值。在 CPU 上用 32 位精度微调 0.5B 模型大约需要 4～6GB 内存，微调 1.5B 模型大约需要 8～12GB 内存。

## CPU 还是显卡

显卡（GPU）有成千上万个计算核心，非常适合神经网络的大规模矩阵运算。一块主流的 NVIDIA 游戏显卡的训练速度，通常是普通 CPU 的 10 倍到几十倍。训练和推理 PyTorch 模型需要 NVIDIA 显卡并安装 CUDA 版本的 PyTorch；AMD 显卡和苹果芯片也有各自的加速方案，但兼容性不如 NVIDIA。

没有独立显卡也可以训练，只是更慢。对于 CPU，核心数越多、支持的指令集越新（AVX2、AVX-512），速度越快。近几年的笔记本和台式机 CPU 大多支持 AVX2。

## 训练时间估算

LoRA 微调时，每个词元的计算量大约是模型参数量的 4 倍（前向 2 倍、反向 2 倍），开启梯度检查点后还要加上一次前向重算。以 1000 条问答样本、约 110 万个词元为例：
- 0.5B 模型：每个词元约 20 亿次浮点运算，总计约 2.2 × 10¹⁵ 次。实际算力 100 GFLOPS 的 CPU 约需 6 小时，200 GFLOPS 的 CPU 约需 3 小时；
- 1.5B 模型：计算量约为 0.5B 的 3.5 倍，CPU 上需要 7～20 个小时，建议放在晚上训练，或者使用显卡。

在一台 4 核的云服务器 CPU 上实测：0.5B 模型每秒约训练 150 个词元，1000 条样本约 2 小时，峰值内存约 4GB；1.5B 模型每秒约 44 个词元，1000 条样本约 7 小时，峰值内存约 8.5GB。

在一块 8GB 显存的 NVIDIA 显卡上，1.5B 模型的 LoRA 微调通常在一小时以内就能完成 1000 条样本。

## 低成本建议

1. 先用 0.5B 模型和少量文档把整个流程跑通，评测效果满意后再换更大的模型和完整的知识库；
2. 先小规模试跑：用 `--max-samples 50` 训练几分钟，确认流程正确、损失在下降，再跑全量；
3. 利用夜间：CPU 训练可以放在晚上进行，程序会定期保存断点，中断后可以用 `--resume` 继续；
4. 如果需要更大的模型，可以借助免费的在线 GPU 环境（如 Google Colab、Kaggle）完成训练，再把 LoRA 结果下载到本地使用。
