# 指令微调与对齐

## 为什么需要微调

预训练得到的"基座模型"（base model）只会续写文本。给它一个问题，它可能接着写出更多问题，而不是回答。要让模型成为好用的助手，需要进一步微调。

## 指令微调（SFT）

指令微调（Supervised Fine-Tuning，监督微调）使用大量"指令—回答"对来训练模型，例如"把这句话翻译成英文"及其标准译文。训练时只对回答部分计算损失，指令部分不计算损失，这样模型学的是"如何回答"，而不是"如何提问"。

指令微调的数据质量比数量更重要。研究表明，几千条高质量、多样化的指令数据，就能让基座模型具备不错的对话能力。

## 基于人类反馈的强化学习（RLHF）

RLHF 是 OpenAI 在 InstructGPT 中使用的对齐方法，分三步：
1. 用指令数据做监督微调；
2. 让人对模型的多个回答排序，用排序数据训练一个奖励模型；
3. 用强化学习算法（PPO）优化模型，让它生成奖励模型打分更高的回答。

RLHF 效果好，但流程复杂、训练不稳定、需要同时加载多个模型，成本很高。

## 直接偏好优化（DPO）

DPO（Direct Preference Optimization）是 2023 年提出的简化方法。它不需要单独训练奖励模型，也不需要强化学习，直接用"更好的回答"和"更差的回答"组成的偏好数据对来训练模型：提高好回答的概率，降低差回答的概率。DPO 实现简单、训练稳定，已被广泛采用。

## 领域微调

在通用助手的基础上，还可以用特定领域的数据继续微调，让模型熟悉领域术语和回答格式。对于知识库问答，一种有效的方法是 RAFT（检索增强微调）：训练数据中同时给出正确资料和干扰资料，教模型从资料中找答案、标注引用，并在资料不足时拒绝回答。

需要注意，微调的主要作用是教会模型"怎么答"（格式、风格、能力），而不是往模型里灌输大量新知识。想让模型掌握大量事实知识，用知识库检索比微调更可靠，也更容易更新。
