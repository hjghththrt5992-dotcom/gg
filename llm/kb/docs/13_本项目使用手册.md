# 本项目使用手册

## 项目简介

本项目是一套低成本的知识库问答系统：用开源小模型（Qwen2.5-0.5B 或 1.5B）负责理解和表达，用本地知识库负责提供知识。它不需要显卡，普通电脑就能运行和微调，也不需要调用任何收费接口，所有数据都保存在本地。

系统由三部分组成：知识库（文档切分、关键词索引和向量索引）、检索器（BM25 与向量混合检索、RRF 融合、可选重排）、生成模型（量化小模型，按资料作答并标注引用）。

## 安装

1. 安装 Python 3.9 或更高版本；
2. 在项目根目录运行 `pip install -r llm/requirements.txt` 安装依赖。国内网络可以加上清华镜像：`pip install -r llm/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`；
3. 如果电脑有 NVIDIA 显卡，需要按 PyTorch 官网的说明安装 CUDA 版本的 PyTorch，否则只会使用 CPU；
4. 可选：安装 `llama-cpp-python` 以使用 GGUF 量化模型，推理速度更快、内存更省。

## 快速开始

依次运行以下命令：
1. `python llm/main.py check`：检测电脑配置，推荐模型大小；
2. `python llm/main.py download`：下载向量模型和问答模型。无法访问 huggingface.co 时会自动改用国内镜像 hf-mirror.com；
3. `python llm/main.py build`：构建知识库索引；
4. `python llm/main.py chat`：在命令行中提问；或者运行 `python llm/main.py web`，然后用浏览器打开 http://127.0.0.1:8000 在网页中提问。

## 添加自己的资料

把文档放进 `llm/kb/docs` 文件夹（可以建子文件夹），支持 md、txt、html、pdf、docx 格式，然后重新运行 `python llm/main.py build` 即可。如果想使用其他文件夹，可以运行 `python llm/main.py build --docs 文件夹路径`。

重建索引时，内容没有变化的文档会复用之前计算好的向量，只有新增或修改的部分需要重新计算，所以更新很快。更新知识不需要重新训练模型。

Markdown 文档中的标题（# 开头的行）会被用来划分小节，建议用标题组织内容，检索效果更好。

## 微调模型（可选）

微调能让小模型更擅长"按资料答题"：更少被无关资料带偏、更会标注引用、资料中没有答案时如实说明。步骤如下：
1. `python llm/main.py gen-qa`：让模型根据知识库每段资料自动出题，生成问答对；
2. `python llm/main.py build-train`：把问答对做成 RAFT 训练样本，其中约 20% 是拒答样本；
3. `python llm/main.py train`：进行 LoRA 微调。可以先加 `--max-samples 50` 试跑；
4. `python llm/main.py eval --finetuned`：评测微调后的效果，与 `python llm/main.py eval` 的结果对比；
5. `python llm/main.py chat --finetuned`：使用微调后的模型问答。

训练过程中程序会定期保存断点，如果中途关机，运行 `python llm/main.py train --resume` 可以接着训练。

## 评测

`python llm/main.py eval --retrieval-only` 只评测检索效果，不需要加载问答模型，几秒钟就能完成。`python llm/main.py eval` 会评测完整的问答效果，包括回答正确率、引用正确率、拒答正确率等。评测题保存在 `llm/kb/eval.jsonl`，换成自己的知识库后，建议按相同格式编写几十道自己的评测题。

## 常见问题

问：回答速度太慢怎么办？
答：可以换用 0.5B 模型（加参数 `--size 0.5b`），或者安装 llama-cpp-python 并运行 `python llm/main.py download --gguf` 下载量化模型，速度通常能提高 2～4 倍。

问：回答不准确怎么办？
答：先运行 `python llm/main.py eval --retrieval-only` 检查检索命中率。如果命中率低，说明问题出在检索，可以改进文档的标题结构，或者加 `--rerank` 启用重排模型；如果命中率高但回答不准，可以换用更大的模型或者进行微调。

问：模型回答"知识库中未找到相关信息"是什么意思？
答：说明检索到的资料中没有能回答问题的内容。这是为了防止模型编造答案而特意设计的行为。可以检查知识库中是否确实包含相关内容。

问：生成的文件保存在哪里？
答：所有生成的文件（模型、索引、训练结果、评测报告）都保存在 `llm/data` 文件夹中，删除后可以重新生成。
