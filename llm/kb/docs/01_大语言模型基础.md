# 大语言模型基础

## 什么是大语言模型

大语言模型（Large Language Model，简称 LLM）是一种用海量文本训练出来的神经网络，它的核心能力是"根据前文预测下一个词元（token）"。模型每次只预测一个词元，把预测结果接到输入后面，再预测下一个，如此循环，就能生成一整段文字。这种生成方式叫做自回归生成。

虽然训练目标只是"预测下一个词"，但当模型参数足够多、训练数据足够丰富时，模型会在这个过程中学会语法、常识、推理、翻译、写代码等多种能力。

## 参数量

参数就是神经网络里可以被训练调整的数字。模型规模通常用参数量表示，例如 0.5B 表示约 5 亿个参数，7B 表示约 70 亿个参数（B 是 billion，十亿）。

参数量决定了模型需要多少内存：
- 以 FP32（32 位浮点数）存储，每个参数占 4 字节；
- 以 FP16 或 BF16（16 位）存储，每个参数占 2 字节；
- 以 4bit 量化存储，每个参数约占 0.5 字节。

例如一个 1.5B 的模型，用 16 位存储约需 3GB 内存，4bit 量化后只需约 1GB。

## 模型能力的来源

大语言模型的训练通常分三个阶段：
1. 预训练：在数万亿词元的通用文本上学习预测下一个词，获得语言能力和世界知识；
2. 指令微调（SFT）：用"指令—回答"格式的数据训练，让模型学会听懂指令、按要求作答；
3. 对齐：用人类偏好数据（如 RLHF、DPO）让回答更有用、更安全。

## 上下文窗口

上下文窗口是模型一次能处理的最大词元数，包括输入和输出。例如 Qwen2.5 系列支持 32K 甚至更长的上下文。超过窗口长度的内容模型看不到。需要注意，小模型虽然"能放下"长上下文，但在很长的输入中找准关键信息的能力明显弱于大模型，因此给小模型的资料应当少而精。

## 小模型的局限与对策

参数少的模型（例如 0.5B～3B）能记住的知识有限，遇到冷门问题容易编造答案，这种现象叫做"幻觉"。对策是把知识放在模型外面：先从知识库里检索相关资料，再让模型根据资料作答，这就是检索增强生成（RAG）。这样小模型只需要负责"读懂资料、组织语言"，不需要记住所有事实。

## 开源小模型

常见的开源小模型有 Qwen（通义千问）、Llama、Gemma、Phi 等系列。其中 Qwen2.5 系列提供 0.5B、1.5B、3B、7B 等多种规模，中文能力较好，并且 0.5B 和 1.5B 版本采用 Apache 2.0 许可证，可以免费商用，适合在普通电脑上部署。
